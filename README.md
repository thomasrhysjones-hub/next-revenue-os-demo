# NEXT Revenue OS | Public demo

An interactive, fictional prototype prepared for the NEXT.io Sales Director assessment.

**Open the app:** https://thomasrhysjones-hub.github.io/next-revenue-os-demo/ (available once GitHub Pages is enabled)

## What it demonstrates

1. Add information from a fictional sponsor enquiry or simulated CRM record.
2. Analyse the opportunity and review the recommended next commercial action.
3. Review an optional customer communication draft and approve it manually.

It also includes illustrative lead intelligence, account-growth suggestions and a 90-day pilot model.

## Important limitations

- Offline, client-side rules provide the immediate analysis. They are not a live AI API call.
- An optional manual ChatGPT hand-off allows model output to be reviewed before importing.
- No connected CRM, real customer data, live sponsor inventory, pricing validation, account verification, or authenticated lead research.
- Nothing is automatically sent to buyers. Do not paste real client, employee or commercial data into this public demonstration.
- The app requests that search engines not index it, but **the site is public**, not access controlled.

## Deployment

In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**. After GitHub publishes, open the URL above in an ordinary browser such as Safari or Chrome. iPhone Files preview may block JavaScript.

Updating `index.html` on `main` publishes the updated client-side app automatically.
